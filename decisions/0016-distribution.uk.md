# D-0016. Поширення: публічний репо, який читають за тегом

> Українська · [English](0016-distribution.md)

**Статус:** прийнято · **Дата:** 2026-10-18 · **Правила:** —

## Контекст

Стандарт має легко застосовуватися на будь-якій машині без ручного копіювання файлів і не прив'язувати користувачів до одного інструмента.

## Рішення

Репо публічне. Короткий промпт у README називає репо і тег релізу; агент завантажує цей реліз неглибоким `git clone` у `~/.cache/standards/<власник>/<репозиторій>/<тег>/` (git — дозволений інструмент хоста; репозиторій входить у шлях, тож форк із тим самим тегом ніколи не візьме чужу теку) і йде за `prompt/start.md`. Плагін Claude Code можна додати пізніше як другий спосіб доставити ті самі файли.

## Розглянуті варіанти

- **Плагін Claude Code зараз.** Слеш-команди й оновлення, але стандарт прив'язується до одного інструмента.
- **Копія стандарту в кожному проєкті.** Копії розходяться, і ніхто не знає, за якою версією живе проєкт.

## Наслідки

Нічого не встановлюється й не копіюється руками, і кожен проєкт читає саме той реліз, який називає.
