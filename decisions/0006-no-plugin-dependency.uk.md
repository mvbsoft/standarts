# D-0006. Стандарт не залежить від жодного плагіна Claude Code

> Українська · [English](0006-no-plugin-dependency.md)

**Статус:** прийнято · **Дата:** 2026-10-18 · **Правила:** AI-03

## Контекст

Перша чернетка спиралася на конкретний плагін робочого циклу, а пізніша зберігала для нього правило-адаптер. Стандарт задуманий для всіх, а цей плагін є не в усіх.

## Рішення

Жодне правило не залежить від плагіна, і стандарт не називає жодного. Єдиний місток — одне речення в AI-03: плагін робочого циклу, який запускає перевірки проєкту, викликає ті самі цілі `make` (`make gates`, `make verify`), а його локальний стан лишається поза git. Правила-адаптера немає.

## Розглянуті варіанти

- **Будувати стандарт навколо плагіна робочого циклу.** Коротше для його користувачів, непридатно для всіх інших.
- **Правило-адаптер для кожного плагіна.** Тримає подробиці одного інструмента в універсальному стандарті й мусить стежити за змінами цього інструмента.

## Наслідки

Основні правила лишаються універсальними. Плагін і розробник перевіряють те саме, бо обидва викликають `make`; усе інше, що потрібно плагіну, — справа самого плагіна.
